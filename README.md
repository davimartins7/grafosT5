# Trabalho 5 - Coloração de Grafos com DSatur

Este repositório contém a implementação do algoritmo DSatur para o problema de coloração de vértices, aplicado ao mapa político do Brasil.

## Requisitos
- Python 3.x
- Classes de grafo da disciplina (`graph.py`, `bag.py`, etc.)

## Estrutura do Projeto
- `src/`: Contém o código fonte (`main.py` e `graph_lib.py`).
- `dados/`: Contém o arquivo `brasil.txt` com a modelagem do mapa.
- `Trabalho5_Grafos_DSatur.ipynb`: Notebook Python com a implementação integrada.

## Como Executar
Para executar via linha de comando:
```bash
python3 src/main.py dados/brasil.txt
```
